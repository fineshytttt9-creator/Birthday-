# Myy Dalli Bitchh — Birthday Website

Included:
- 3 birthday photos
- the cat photo you uploaded
- dark + pink cute aesthetic
- interactive buttons
- floating hearts
- confetti ending
- personalized roast text

Add memes:
- Put your own meme images inside `assets/`.
- Edit the meme cards in `index.html` if you want custom captions.

Add music:
- Use an audio file you have the right to use.
- Rename it `music.mp3`.
- Put it inside `assets/`.
- The site attempts playback after a button click.

Free hosting: GitHub Pages.
